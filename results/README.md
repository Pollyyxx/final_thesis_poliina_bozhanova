# Results

This folder contains saved model evaluation and backtest outputs. The current target is the next bar's open to close return, entered at the next bar open after the signal bar has completed.

- `advanced_model_fold_metrics.csv`: fold level accuracy, balanced accuracy, F1 and ROC AUC for the five model and baseline approaches.
- `advanced_model_predictions.csv`: out of sample predictions, next bar open to close returns and shared test timestamps used for model comparison and backtesting. The files include the next bar open and close prices for audit.
- `long_or_cash_backtest_summary.csv`: cumulative net return, maximum drawdown, annualized daily Sharpe, exposure, turnover and trading activity by model and cost scenario.
- `long_or_cash_backtest_daily_returns.csv`: daily gross and net returns for each model/cost scenario.
- `indicator_ablation_fold_metrics.csv` and `indicator_ablation_summary.csv`: five fold metrics for base features and base plus indicator feature sets.
- `indicator_ablation_deltas.csv`: augmented minus base mean fold metric differences.
- `indicator_ablation_predictions.csv`: paired, shared timestamp predictions for both feature sets.
- `indicator_ablation_backtest_summary.csv` and `indicator_ablation_backtest_daily_returns.csv`: matched long or cash results for both feature sets across the existing per side cost scenarios.
- `robustness_fold_metrics.csv`: model metrics for each of the five existing chronological test folds.
- `robustness_backtest_by_fold.csv` and `robustness_backtest_daily_by_fold.csv`: per fold strategy summaries and daily returns. Each fold starts and ends flat; fold returns are not compounded together.
- `robustness_backtest_stability.csv`: mean, median, range and positive fold count for each model and cost scenario.
- `model_strategy_comparison.csv`: joined predictive summary and continuous period backtest results at zero and 1 bp per side, generated by notebook 08.
- `signal_to_execution_gap.csv`: mean accuracy lift over the majority baseline alongside zero cost and 1 bp per side strategy returns for each ETF/model.

To recompute the model comparison, including majority and direction persistence baselines, run `python_code/run_advanced_models.py` from the project root. The notebook reads the saved outputs by default and does not retrain models when they are already present.

To recompute the long or cash results from saved predictions, run `python_code/run_backtest.py`. Cost scenarios are illustrative all in transaction cost and slippage rates per side, not broker specific estimates. Fold results are a stability check on periods already reviewed, not a new untouched final test.

To recompute the indicator ablation, run `python_code/run_indicator_ablation.py` in the project environment. It leaves the original baseline model and backtest outputs unchanged. Notebook 08 joins the saved results for review; it does not retrain models or tune settings.

## Cost evidence

The input files contain five minute OHLCV bars, not bid/ask or NBBO quotes, order sizes, routes, broker fee schedules or actual fills. The backtest's next open/next close fills and 0, 1, 2.5, 5 and 10 basis point per side values are therefore an execution assumption and sensitivity grid, not measured trading costs. The 0 bp row is a gross reference. Regulatory fee schedules change over time and do not determine spread or slippage; see the cost evidence review in `docs/methodology_and_next_steps.md` for the official SEC and FINRA references.
